## 🚀 Quick Start

### 1. Frontend (Browser)
```bash
# Open in browser
open frontend/index.html
```

### 2. Backend API (Python)
```bash
# Install dependencies
pip install fastapi uvicorn

# Run API
python api/main.py
# Server runs on http://localhost:8000
```

### 3. Test in Console
```javascript
// System commands
System.emissary("Kamata")              // Get emissary
System.memory.set("key", "value")     // Set memory
System.run("quickAdd", 2, 3)          // Execute command
System.getStatus()                     // System status

// ORA System
System.oraSystem.listAssets()          // List all assets
System.oraSystem.getAsset("ORA-001")   // Get asset
System.oraSystem.getValuation("ORA-001") // Get valuation

// Bridge system
analyzeAssetThroughEmissary("Kamata", "ORA-001")
```

## 🧠 Core Systems

### Emissaries (Symbolic AI Agents)

**Kamata** - Emotional Intelligence
- Role: Perceives emotional resonance and intuitive truth
- Frequency: 528Hz (Love)
- Verdict basis: Intuition + Potential Index

**Amata** - Security & Boundaries
- Role: Ensures safety and validates integrity
- Frequency: 432Hz (Healing)
- Verdict basis: Security Score

**Ntala** - Storage & Memory
- Role: Organizes and preserves knowledge
- Frequency: 108Hz (Divine)
- Verdict basis: Volume + Organization

**Mandingus** - Control & Governance
- Role: Commands and coordinates all systems
- Frequency: 741Hz (Crown/Sovereignty)
- Verdict basis: Overall Score + Authority

### ORA System (Digital Asset Registry)

Each asset has:
- **ID**: ORA-001, ORA-002, etc.
- **Metadata**: Name, type, creation date
- **Value**: Numerical valuation
- **Volume**: Storage/transaction volume
- **Valuation**: Score, potential index, security score
- **NFT Ready**: ERC721 metadata pre-generated
- **Blockchain**: Polygon-ready

### Bridge Layer

Connects consciousness (Kamara) with economy (ORA):
```javascript
Portal: Emissary → Asset → Analysis
  ↓
  Emissary characteristics applied to asset valuation
  ↓
  Symbolic verdict returned (STRONG HOLD, EXECUTE, etc.)
```

## 🔗 API Endpoints (FastAPI)

### Assets
```
GET  /assets                    # List all assets
GET  /assets/{asset_id}         # Get specific asset
```

### Valuations
```
GET  /valuation/{asset_id}      # Get asset valuation
```

### Inquiries
```
POST /inquiry                   # Submit buyer inquiry
GET  /inquiry/{inquiry_id}      # Get inquiry details
GET  /inquiries                 # List all inquiries
```

### Analysis
```
POST /emissary/{emissary_name}/analyze/{asset_id}
     # Get emissary analysis of asset
```

### NFT
```
GET  /nft/{asset_id}/metadata   # Get ERC721 metadata
```

## 🔮 Example Workflow

1. **User selects Emissary** (e.g., Kamata)
2. **User selects Asset** (e.g., ORA-001)
3. **System triggers Analysis**:
   - Retrieves emissary characteristics
   - Pulls asset data from ORA registry
   - Calculates valuation metrics
   - Applies emissary logic to verdict
4. **Bridge returns Analysis**:
   ```json
   {
     "emissary": "Kamata",
     "asset": "ORA-001",
     "verdict": "STRONG HOLD",
     "valuation": {"score": 87, "potential": 78},
     "emissaryRole": "Emotional Intelligence"
   }
   ```
